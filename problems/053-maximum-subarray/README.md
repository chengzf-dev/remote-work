# Maximum Subarray

This function finds the contiguous subarray with the largest sum in a given integer array.

## Usage

Create an array and call the function:

```
const result = maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4]);
console.log(result); // Outputs: 6
```

## Time Complexity
- O(n) - Iteration through the array occurs once.

## Space Complexity
- O(1) - Utilizes constant space regardless of input size.
