# LC-053 Maximum Subarray\n\nThis directory contains the solution for the Maximum Subarray problem.\n\n## Problem Statement\nFind the contiguous subarray within a one-dimensional array of numbers which has the largest sum.\n\n## Solution\n- The implementation uses Kadane's algorithm to find the maximum sum in O(n) time and O(1) space complexity.\n\n## Testing\n- Tests are written in TypeScript. Ensure you have the necessary libraries to run tests.\n
