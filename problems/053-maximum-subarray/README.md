# LC-053 Maximum Subarray

This folder contains the solution and tests for the Maximum Subarray problem.

## Problem Statement

Given an integer array, find the contiguous subarray with the largest sum and return its sum.

## Files
- : Implementation of the Maximum Subarray algorithm.
- : Test cases for the implementation.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
