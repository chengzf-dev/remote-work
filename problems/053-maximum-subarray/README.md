# Maximum Subarray\n\nThe maxSubArray function finds the contiguous subarray within a one-dimensional array of numbers which has the largest sum using Kadane's algorithm.\n\n## Function Signature\n\nfunction maxSubArray(nums: number[]): number\n\n## Complexity\n- **Time Complexity:** O(n) - We traverse the array once.\n- **Space Complexity:** O(1) - No additional space apart from variables.\n\n## Test Cases\n1. Input: [-2,1,-3,4,-1,2,1,-5,4] should return 6.\n2. Input: [1] should return 1.\n3. Input: [5,4,-1,7,8] should return 23.\n4. Input: [-1,-2,-3] should return -1 (the max negative number).\n
