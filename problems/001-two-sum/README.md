# LC-001 Two Sum\n\n## Problem Description\nGiven an array of integers and a target value, return the indices of the two numbers such that they add up to the target.\n\n## Solution\nThis solution uses a hash map to store the indices of the numbers as we iterate through the array. For each number, we calculate its complement by subtracting the number from the target. If the complement exists in the map, we return the current index and the index of the complement. This approach allows us to solve the problem in O(n) time complexity.\n\n## Complexity\n- Time Complexity: O(n)\n- Space Complexity: O(n)\n
