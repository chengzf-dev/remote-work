# Two Sum Problem\nThis solution finds two indices of numbers in an array that add up to a target sum.\n\n## Approach\n- We use a hash map to track the indices of the numbers as we iterate through the array.\n- For each number, we calculate its complement (target - num) and check if it already exists in the hash map.\n- If it does, we return the indices; if not, we store the index of the current number.\n\n## Complexity\n- Time Complexity: O(n)\n- Space Complexity: O(n)
