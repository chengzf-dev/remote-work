# LC-001 Two Sum\n\nThis directory contains the solution for the Two Sum problem.\n\n## Problem Statement\nGiven an array of integers, return indices of the two numbers such that they add up to a specific target.\nYou may assume that each input would have exactly one solution, and you may not use the same element twice.\n\n## Solution\n- The implementation uses a hash map for O(n) time complexity and O(n) space complexity.\n- The function returns the indices of the two numbers that add up to the target.\n\n## Testing\n- Tests are written in TypeScript and can be run using Node.js.\n- Ensure you have installed the necessary TypeScript and assertion libraries to run tests.\n
