# LC-001 Two Sum\n\n## Problem Statement\nThe goal is to find the indices of two numbers in an array that add up to a specific target. You must handle cases with duplicates and ensure optimal performance.\n\n## Solution\nThe solution is implemented using a hash map to achieve a time complexity of O(n) while storing values and their respective indices.\n\n## Time Complexity\nO(n) - the hash map lookup is O(1) on average.\n\n## Space Complexity\nO(n) - we are storing elements in the hash map.
