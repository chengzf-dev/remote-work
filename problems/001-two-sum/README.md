# Two Sum Problem

## Overview
The Two Sum problem requires finding the indices of two numbers in an array that add up to a given target.

## Solution
The solution uses a hash map to achieve an O(n) time complexity by storing numbers and their indices, checking for complements as we iterate through the array.

## File Explanations
- `solution.ts`: The implementation of the Two Sum algorithm.
- `solution.test.ts`: Contains test cases to validate the functionality of `twoSum`.
