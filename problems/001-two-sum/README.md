# Two Sum\n\nThis function takes an array of integers and a target integer and returns the indices of the two numbers that add up to the target.\n\n## Usage\n\n`twoSum([2, 7, 11, 15], 9);`\n\n## Example\n\n`\nconst result = twoSum([2, 7, 11, 15], 9);\nconsole.log(result); // Outputs: [0, 1]\n`\n\n## Time Complexity\n- O(n) - because we iterate through the array once.\n\n## Space Complexity\n- O(n) - we store the elements of the array in a hash map.\n
