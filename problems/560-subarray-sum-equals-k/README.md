# Subarray Sum Equals K\nThis solution counts the number of continuous subarrays whose sum equals to k.\n\n## Approach\n- We use a hash map to store the cumulative sum and its frequency.\n- For each number, we calculate the cumulative sum and check how many times (previous sums) we have seen it mapped to k.\n- Increment our count accordingly.\n\n## Complexity\n- Time Complexity: O(n)\n- Space Complexity: O(n)
