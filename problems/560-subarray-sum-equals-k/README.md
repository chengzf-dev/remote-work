# Subarray Sum Equals K\n\nThe subarraySum function counts the number of continuous subarrays whose sum equals k. It utilizes a prefix sum and hash map for efficient counting.\n\n## Function Signature\n\nfunction subarraySum(nums: number[], k: number): number\n\n## Complexity\n- **Time Complexity:** O(n) - We traverse the list only once.\n- **Space Complexity:** O(n) - We store prefix sums in a hash map.\n\n## Test Cases\n1. Input: [1, 1, 1], k = 2 should return 2.\n2. Input: [1, 2, 3], k = 3 should return 2.\n3. Input: [0, 0, 0], k = 0 should return 6 (six possible subarrays).\n4. Input: [-1, -1, 1], k = 0 should return 1.\n
