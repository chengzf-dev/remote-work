# LC-560 Subarray Sum Equals K\n\nThis directory contains the solution for the Subarray Sum Equals K problem.\n\n## Problem Statement\nGiven an integer array nums and an integer k, return the total number of subarrays whose sum equals to k.\n\n## Solution\n- The implementation uses prefix sum and a hash map to maintain counts of prefix sums.\n- The function runs in O(n) time complexity and O(n) space complexity.\n\n## Testing\n- Tests are written in TypeScript. Ensure you have the necessary libraries to run tests.\n
