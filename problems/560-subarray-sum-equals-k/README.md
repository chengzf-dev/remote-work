# LC-560 Subarray Sum Equals K

This folder contains the solution and tests for the Subarray Sum Equals K problem.

## Problem Statement

Given an integer array and an integer k, return the total number of subarrays whose sum equals to k.

## Files
- : Implementation to count subarrays with sum = k.
- : Test cases for the implementation.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
