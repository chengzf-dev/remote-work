# LC-560 Subarray Sum Equals K\n\n## Problem Statement\nGiven an integer array nums and an integer k, return the total number of continuous subarrays whose sum equals to k.\n\n## Solution\nThe solution uses a prefix sum approach combined with a hash map for an optimal O(n) solution.\n\n## Time Complexity\nO(n) - only iterate through the array once.\n\n## Space Complexity\nO(n) - requires extra space for the hash map.
