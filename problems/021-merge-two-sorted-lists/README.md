# Merge Two Sorted Lists\n\nThe mergeTwoLists function merges two sorted linked lists into one sorted linked list. This implementation uses a dummy node technique for simplicity.\n\n## Function Signature\n\nfunction mergeTwoLists(l1: ListNode | null, l2: ListNode | null): ListNode | null\n\n## Complexity\n- **Time Complexity:** O(n + m) - We traverse both lists, where n is the length of l1 and m is the length of l2.\n- **Space Complexity:** O(1) - No extra space is used except for pointers.\n\n## Test Cases\n1. Merging lists [1, 2, 4] and [1, 3, 4] should return [1, 1, 2, 3, 4, 4].\n2. Two empty lists should return an empty list.\n3. Merging a list with an empty list should return the non-empty list.\n
