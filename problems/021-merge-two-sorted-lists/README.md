# Merge Two Sorted Lists\nThis solution merges two sorted linked lists and returns it as a new sorted list.\n\n## Approach\n- We use a dummy node to simplify merging logic.\n- Iterate through both lists, appending the smaller node to the merged list.\n- Once one list is exhausted, append the non-exhausted list to the merged list.\n\n## Complexity\n- Time Complexity: O(n + m)\n- Space Complexity: O(1)
