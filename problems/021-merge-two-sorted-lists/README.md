# LC-021 Merge Two Sorted Lists\n\n## Problem Description\nMerge two sorted linked lists and return it as a single sorted list.\n\n## Solution\nThis solution uses a dummy node to simplify the merging process. We traverse both linked lists, comparing their node values and attaching the smaller node to the merged list until we reach the end of both lists.\n\n## Complexity\n- Time Complexity: O(n + m)\n- Space Complexity: O(1) for iterative approach\n
