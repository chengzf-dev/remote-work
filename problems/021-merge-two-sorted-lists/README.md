# LC-021 Merge Two Sorted Lists\n\n## Problem Statement\nGiven two sorted linked lists, merge them into one sorted linked list. The merged list should be made by splicing together the nodes of the first two lists.\n\n## Solution\nThe solution iterates through both lists, using a dummy node to simplify merging, resulting in a time complexity of O(n + m) for the merge.\n\n## Time Complexity\nO(n + m) - traversing each list once.\n\n## Space Complexity\nO(1) for iterative implementation (constant space).
