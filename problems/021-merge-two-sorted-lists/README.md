# Merge Two Sorted Lists Problem

## Overview
This problem requires merging two sorted linked lists into one sorted linked list.

## Solution
The solution utilizes a dummy node to simplify the merging process, ensuring an efficient O(n + m) time complexity.

## File Explanations
- `solution.ts`: The implementation of the mergeTwoLists algorithm.
- `solution.test.ts`: Contains test cases to validate the functionality of `mergeTwoLists`.
